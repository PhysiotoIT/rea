# Karta: jedna hipoteza, jedna próba

Autorska pomoc do rozumowania klinicznego. Można z niej korzystać także poza UHPC.

| Pytanie                          | Miejsce na notatkę                                        |
| -------------------------------- | --------------------------------------------------------- |
| Co osoba chce móc robić?         | Konkretne zadanie, np. sięganie lub zatrzymanie po biegu. |
| Co aktualnie ogranicza zadanie?  | Obserwacja i odczucie osoby; oddziel interpretację.       |
| Jak wygląda pomiar początkowy?   | Pozycja, podparcie, tempo, obciążenie, objaw i wynik.     |
| Jaką hipotezę testuję?           | Jedno zdanie; przewidywanie możliwe do sprawdzenia.       |
| Co dokładnie zmieniam?           | Jeden główny warunek, opisany tak, by powtórzyć próbę.    |
| Czego oczekuję po zmianie?       | Ustal przed retestem, co uznasz za korzystną odpowiedź.   |
| Co faktycznie się zmieniło?      | Wynik retestu i ważnego zadania.                          |
| Czy to się powtarza i utrzymuje? | Kolejna próba, późniejszy kontakt, reakcja na trening.    |
| Co zrobię przy braku odpowiedzi? | Modyfikacja lub porzucenie hipotezy, dalsze badanie.      |

Przykład zapisu bez mieszania obserwacji z mechanizmem:

„Po zmianie podparcia pacjent zgłosił łatwiejsze sięgnięcie. W retestowanej pozycji uzyskał większy zakres. Sprawdzę odpowiedź przy codziennym zadaniu. Mechanizm tej zmiany nie został ustalony”.

Unikaj dopisywania pewnej diagnozy wyłącznie dlatego, że wynik jednej próby odpowiadał przewidywaniu.
